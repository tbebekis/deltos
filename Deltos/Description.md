# Deltos

## Σκοπός

Το **Deltos** είναι η εξέλιξη του παλιού StoryWriter. Δεν προορίζεται
μόνο για μυθιστορήματα, αλλά για κάθε είδους δομημένο κείμενο:

-   Μυθιστορήματα
-   Τεχνικά βιβλία
-   Δοκίμια
-   Documentation
-   Άρθρα
-   Σημειώσεις

Η φιλοσοφία του είναι να αποτελεί **Workspace Συγγραφής** και όχι απλώς
έναν text editor.

------------------------------------------------------------------------

# Βασικό Μοντέλο

``` text
Project
    Document
        Folder
            Folder
            Text
```

-   Ένα **Project** μπορεί να περιέχει πολλά Documents.
-   Κάθε **Document** ορίζει τη δική του δομή.
-   Τα **Folders** μπορούν να περιέχουν ταυτόχρονα άλλα Folders και
    Texts.
-   Τα **Texts** είναι markdown αρχεία.

Κατά τη δημιουργία ενός Document ο χρήστης ορίζει:

-   τη δομή των επιπέδων (π.χ. Part → Chapter → Section),
-   τις ονομασίες των επιπέδων.

Η δομή αυτή παραμένει σταθερή για όλη τη ζωή του Document.

------------------------------------------------------------------------

# Ταυτότητα

Κάθε αντικείμενο διαθέτει μοναδικό GUID Id.

Τα ονόματα των folders/files στον δίσκο έχουν μορφή:

``` text
001. Περιπλάνηση
002. Η Άφιξη
003. Η Σύγκρουση
```

Η αρίθμηση:

-   καθορίζει τη σειρά εμφάνισης,
-   χρησιμοποιείται και στο filesystem,
-   διατηρεί το TreeView και τον δίσκο απόλυτα συγχρονισμένα.

Μετακίνηση στοιχείου σημαίνει επαναρίθμηση όλων των siblings και
αντίστοιχη μετονομασία των folders/files.

------------------------------------------------------------------------

# Components

Κάθε Project διαθέτει βιβλιοθήκη Components.

Παραδείγματα:

-   Χαρακτήρες
-   Πλανήτες
-   Μηχανές
-   Θρησκείες
-   Πολιτεύματα
-   Οργανισμοί

Κάθε Component διαθέτει:

-   Title
-   Category
-   Tags
-   Text

Οι Categories και τα Tags δεν έχουν ξεχωριστούς πίνακες. Προκύπτουν
δυναμικά από τα υπάρχοντα Components.

Τα Components μπορούν να εξαχθούν ως Wiki.

------------------------------------------------------------------------

# Text

Κάθε Text περιέχει:

-   Κύρια γλώσσα
-   Δευτερεύουσα γλώσσα
-   Abstraction
-   Draft

Οι δύο γλώσσες εμφανίζονται δίπλα-δίπλα με splitter και η δεύτερη μπορεί
να αποκρύπτεται.

------------------------------------------------------------------------

# Editor

Ο editor ανοίγει σε TabControl.

Για κάθε Text υπάρχουν tabs:

-   Text
-   Abstraction
-   Temp

Αντίστοιχα ανοίγουν και οι editors των Components.

------------------------------------------------------------------------

# Link Items

Ένα Link Item αποτελεί αναφορά προς:

-   Folder
-   Text
-   Component

Χρησιμοποιείται από:

-   Search Results
-   Quick View

Δεν αποτελεί πραγματικό αντικείμενο του Project.

------------------------------------------------------------------------

# Search

Η αναζήτηση επιστρέφει προσωρινό tree από Link Items.

Αναζητά:

-   Text
-   Abstraction
-   Temp
-   Components

------------------------------------------------------------------------

# Quick View

Προσωρινή λίστα από Link Items προς Texts και Components.

Χρησιμοποιείται ως προσωπικός χώρος γρήγορης πρόσβασης.

------------------------------------------------------------------------

# Global Temp Texts

Το Project διαθέτει λίστα προσωρινών markdown κειμένων.

Παράδειγμα:

``` text
001. Ιδέα για το τέλος
002. Διάλογος
003. Σημειώσεις
```

------------------------------------------------------------------------

# Layout

``` text
+---------------------------------------------------------------+
| Toolbar                                                       |
+---------------------------------------------------------------+
| Left Sidebar |             Editors (TabControl)               |
|--------------|----------------------------------------------- |
| Documents    |  Text (Primary / Secondary)                    |
| Components   |  Abstraction                                   |
| Categories   |  Temp                                          |
| Tags         |                                                |
| Search       |                                                |
| Quick View   |                                                |
| Temp Texts   |                                                |
+--------------+------------------------------------------------+
| Status Bar                                                   |
+---------------------------------------------------------------+
```

Το αριστερό Sidebar περιέχει:

-   Documents
-   Components
-   Categories
-   Tags
-   Search
-   Quick View
-   Temp Texts

Ο κύριος χώρος αφιερώνεται στους editors.

------------------------------------------------------------------------

# Βασική Αρχή

Το Deltos δεν είναι "Story Writer".

Είναι ένα ολοκληρωμένο **Workspace Συγγραφής**, ικανό να υποστηρίξει από
μυθιστορήματα μέχρι τεχνικά βιβλία και μεγάλα συγγραφικά έργα.
